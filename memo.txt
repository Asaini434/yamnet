## Project Overview

This project explores the adaptation of YAMNet, a lightweight audio event
classification model trained on Google’s AudioSet, for music genre
classification and mobile deployment. Using transfer learning, we build a
custom classifier on top of YAMNet embeddings and evaluate the model under
different loss functions and realistic audio distortions. The final model is
exported to TensorFlow Lite (TFLite) for on-device inference.

## Objectives

- Adapt YAMNet for transfer learning using a downstream music genre dataset.
- Evaluate multiple loss functions and compare their impact on classification
  performance.
- Analyze model robustness under common audio distortions such as noise, pitch
  shifting, and time stretching.
- Export a deployable TensorFlow Lite model suitable for mobile devices.

The project is organized to support modular experimentation and team-based

--------------------------------------------------
2. Source Code (src/)
--------------------------------------------------

The src/ directory contains all executable code.

src/yamnet_backbone.py
- Loads the pretrained YAMNet model from TensorFlow Hub.
- Converts raw 16 kHz mono audio waveforms into YAMNet embeddings.
- Provides helper functions for mapping waveforms to fixed-size embeddings.
- This file implements the core model adaptation required for transfer learning.

src/classifier_model.py
- Defines a lightweight neural network classifier that operates on
  1024-dimensional YAMNet embeddings.
- The classifier outputs logits for the target dataset classes.
- This design allows YAMNet to remain frozen while the classifier is trained.

src/train.py
- Provides the main training pipeline.
- Wires together dataset loading, YAMNet embedding extraction, and classifier
  training.
- Includes placeholders for dataset loading to allow flexible dataset selection.
- Uses standard training callbacks and metrics.
- This script serves as the integration point for loss functions, evaluation,
  and robustness extensions.

src/eval.py
- Computes core classification metrics on the test set including accuracy, precision, recall, etc.
- Generates normalized confusion matrices to visualize per-class performance and misclassification patterns.
- Supports optional confusion matrix heatmap visualization using seaborn.
- Provides detailed per-class performance breakdowns exported as JSON.

src/embed_tsne.py
- Performs embedding space analysis on YAMNet's high-dimensional feature representations.
- Computes cluster quality metrics to quantify genre separation.
- Applies t-SNE dimensionality reduction for 2D visualization of genre clustering patterns.
- Outputs CSV coordinates, cluster metrics JSON, and visualizations showing genre relationships and homogeneity patterns.

src/cross_dataset_eval.py
- Evaluates cross-dataset generalization by testing GTZAN-trained models on FMA dataset.
- Measures performance degradation and embedding space quality across different data distributions.
- Generates side-by-side t-SNE visualizations comparing genre clustering between source and target datasets.
- Quantifies label drift by analyzing how nominally identical genre labels manifest differently across datasets.
- Outputs JSON metrics and overlay visualizations demonstrating domain shift.

src/export_tflite.py
- Builds a serving model that combines YAMNet and the trained classifier.
- Converts the model into TensorFlow Lite format for mobile deployment.
- Outputs a .tflite file suitable for on-device inference.

src/losses.py
- Defines 3 loss functions: Sparse Categorical Entropy Loss, Categorical Entropy Loss with
  Label Smoothing, and Focal Loss with various parameters.
- Uses the train function from train.py.
- Experiments training the model with defined loss functions. 
- Outputs a graph displaying the validation loss and accuracy with different loss functions. 

src/trainAugment.py
-Builds off the base train.py
-After reading training data extend training dataset by randomly augmenting data to show distortions

src/robustness.py
- Script to run different robustness tests on original model
- Call eval.py with different distortions DISTORTIONS = ["noise", "gain", "time_stretch", "pitch_shift", "crop"]

src/distortionPlots.py
-Script to plot results of robustnesss evaluations
-Using results in results file creates accuray vs distorion level curves

--------------------------------------------------
5. Design Rationale
--------------------------------------------------

The codebase is designed with modularity in mind:
- The pretrained YAMNet backbone is isolated from downstream task logic.
- Classifier training, loss functions, evaluation, and robustness analyses can
  be developed independently.
- The export pipeline ensures that trained models can be deployed on mobile
  devices, aligning with the course focus on on-device AI.
